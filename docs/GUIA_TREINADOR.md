# Guia do Treinador — Copa Brasil de Talentos 2026

Dez passos para deixar a equipe pronta na plataforma. Dá para fazer tudo pelo celular.
Versão web para enviar aos treinadores: publicada como Artifact (link compartilhável).

## Acesso

- **Endereço:** `https://www.cassianogalvao.com.br/torneio-online/login`
- **E-mail:** o que a organização enviou para o treinador.
- **Senha inicial:** definida pela organização (`COPA_TRAINER_INITIAL_PASSWORD` no seed). O treinador troca no passo 2.

## Passo a passo

1. **Entrar** — abrir o endereço, digitar e-mail e senha inicial, tocar em Entrar.
2. **Trocar a senha** — menu → Meu perfil → Alterar senha.
3. **Conferir a equipe** — menu → Equipes e Atletas → Equipes → Abrir (a própria equipe). Aqui ficam Comissão técnica e Formação.
4. **Comissão técnica** — na página da equipe → Comissão técnica → Cadastrar. Função (treinador, auxiliar, preparador físico, massagista…), nome e foto opcional. Caminho: `Equipes → Abrir → Comissão técnica → Cadastrar`.
5. **Cadastrar atletas** — menu → Atletas → Cadastrar atleta. Por jogador: nome completo, data de nascimento, posição, foto do rosto e foto/PDF de documento com foto. Regulamento pede 22 atletas.
6. **Inscrever no campeonato** — menu → Inscrições → Nova inscrição → escolher o atleta → salvar → Enviar para análise. Uma por atleta.
7. **Acompanhar o status** — na lista de Inscrições (Enviadas, Em análise, Pendente, Aprovadas…).
8. **Resolver pendências** — status Pendente ou coluna Pendências → Abrir → ler o motivo → corrigir → reenviar.
9. **Elenco oficial** — status Aprovadas → atleta entra no Elenco oficial (botão no topo de Inscrições). É o elenco liberado para jogar.
10. **Tabela de jogos** — menu → Operação → Tabela e partidas.

## O que cada status de inscrição significa

| Status | Significado | O que fazer |
| --- | --- | --- |
| Rascunho | Começou mas não enviou | Abrir e Enviar para análise |
| Enviadas / Em análise | Está com a organização | Aguardar |
| Pendente | Falta corrigir algo | Abrir, ler o motivo, ajustar, reenviar |
| Aprovadas | Atleta liberado | Já está no elenco oficial |
| Rejeitadas | Não foi aceita | Falar com a organização |
| Suspensas / Canceladas | Atleta fora por decisão da organização | Falar com a organização |

## Anexar foto ou documento (celular)

Na janela de upload: **Fototeca/Galeria** para imagem salva, **Tirar foto** para fotografar na hora, **Escolher arquivo** para PDF. Os campos de foto/documento aceitam as três opções.
