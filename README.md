# Plataforma de Gestao de Torneios MVP

## Objetivo

Definir o MVP simplificado de uma plataforma para criar, organizar, operar e publicar campeonatos de futebol.

## Stack prevista

PHP 8.2, MySQL, HTML, CSS e JavaScript, com hospedagem em Apache/cPanel.

## Situacao atual

Planejamento inicial. Nenhum modulo funcional foi implementado neste repositorio.

Comandos de instalacao, migrations, seeds e testes ainda nao estao disponiveis.
